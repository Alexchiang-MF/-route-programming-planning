========================================
  主線車輛規劃系統 — 前置設定說明書
========================================

【系統需求】
  作業系統：Windows 10 / 11（64位元）
  Python：3.8 以上版本

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【步驟一：安裝 Python（若尚未安裝）】

  1. 開啟瀏覽器，前往 https://www.python.org/downloads/
  2. 下載最新版 Python 3（例如 Python 3.11）
  3. 執行安裝程式，☑ 務必勾選「Add Python to PATH」
  4. 安裝完成後，開啟「命令提示字元」輸入以下指令確認版本：
       python --version
     應顯示類似：Python 3.11.x

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【步驟二：安裝所需套件】

  方法 A（建議）：直接雙擊本資料夾內的「安裝套件.bat」即可自動安裝。

  方法 B（手動）：
  1. 開啟「命令提示字元」
  2. 切換到本程式資料夾，例如：
       cd C:\Users\你的名字\Desktop\主線編成規劃
  3. 輸入以下指令：
       pip install -r requirements.txt

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【步驟三：確認 Excel 資料檔案】

  執行前請確認以下 Excel 檔案放在程式同一資料夾內：

    模組一特殊路線.xlsx
    模組二特殊店.xlsx
    模組四台北.xlsx
    模組四基隆.xlsx
    模組四宜蘭.xlsx
    模組四新北.xlsx
    模組四新竹.xlsx
    模組四桃園.xlsx
    模組四苗栗.xlsx

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【步驟四：執行程式】

  ▶ 方式一：命令列執行（輸出 Excel 報表）
    雙擊「執行規劃程式.bat」
    報表將自動存至 output\ 資料夾

  ▶ 方式二：網頁介面（可上傳自訂資料）
    雙擊「啟動網頁介面.bat」
    瀏覽器將自動開啟 http://localhost:5001

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【常見問題】

  Q：雙擊 .bat 一閃即消？
  A：Python 未安裝或未加入 PATH，請重做步驟一。

  Q：出現「ModuleNotFoundError」？
  A：套件未安裝，請重做步驟二。

  Q：出現「找不到 Excel 檔案」？
  A：確認步驟三的所有檔案都在同一資料夾。

  Q：網頁介面開啟後空白？
  A：等待約 5 秒後重新整理瀏覽器。

【輸出結果】

  規劃完成後，報表存放於：
    output\路線規劃報告_YYYYMMDD_HHMMSS.xlsx

  內容包含：
  ・各路線門市清單與箱數
  ・車輛指派（5噸／8噸）
  ・預估里程與時間
  ・跨縣市整併資訊
  ・警告事項
